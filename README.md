# 豆包会话打印（Chrome / Edge 扩展）

让豆包分享页（`https://www.doubao.com/thread/…`）能正常多页打印、导出 PDF，也能导出成 EPUB 电子书。

## 现状问题

分享页的对话内容放在一个 `div.flex-1.overflow-y-scroll` 的滚动容器里：容器只有一屏高，
内容却有上万像素。Chrome 打印时会裁切 `overflow: scroll/auto` 的容器，于是只能打出一页。

实测（Chrome 156 无头打印管线，A4）：

| 条件 | 输出页数 | 内容 |
| --- | --- | --- |
| 1440×900 视口，未打补丁 | 1 页 | 仅 85 字符（一屏内容） |
| 打过补丁，再打印 | 15 页 | 全文完整，末页已是文章结尾 |

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开「开发者模式」。
2. 「加载已解压的扩展程序」，选择本目录（含 `manifest.json` 的文件夹）。
3. 打开任意豆包分享页，右下角会出现「打印全文」按钮。

## 使用

三种触发方式，效果相同：

- 页面右下角的「打印全文」按钮（可点 `×` 收起）；
- 点击工具栏中的扩展图标；
- 快捷键 `Alt+Shift+P`（可在 `chrome://extensions/shortcuts` 改）。

也可以直接按浏览器自带的 `Ctrl+P`：插件监听 `beforeprint`，会先把页面还原成完整页面再出图。

打印对话框里选「另存为 PDF」即可导出。

## 导出 EPUB

点右下角「导出 EPUB」，文件会下载到浏览器默认下载目录，文件名形如
`Michael Levin（迈克尔・列文）_20261106.epub`。

成品结构（EPUB 3，可直接导入 Apple Books / Kindle（转换后）/ 多看 / 微信读书等）：

- `mimetype`（未压缩、排首位）→ `META-INF/container.xml` → `OEBPS/content.opf`
- 封面页（标题、导出日期、来源链接）
- 按「一轮对话」分章（用户提问 + AI 回答），章名取提问前 26 字
- `nav.xhtml`（EPUB3 目录）+ `toc.ncx`（兼容旧阅读器）
- `style.css`：正文字体、标题层级、引用块、代码块（自动换行）、表格、图片自适应的阅读排版
- 图片会尝试抓取二进制内嵌进书里；抓不到（跨域受限）的会丢弃，不留外链

## 插件做了什么

1. **解除裁切**：沿对话内容根节点向上逐级把 `height / max-height / overflow / flex` 改成
   内容自适应（并保存原值），打印结束后完整还原，不影响页面正常浏览。
2. **加载全文**：打印前反复滚到底部，直到滚动高度不再变化，确保懒加载 / 长会话的消息都渲染出来。
3. **清理界面**：隐藏右下角的「用豆包继续对话」浮条、其他固定悬浮层，以及每轮回答下方的
   复制 / 重新生成等操作按钮。
4. **排版适配纸张**：
   - `@page` 边距 12mm / 10mm；
   - 图片、SVG、表格、代码块不超出纸张宽度，代码块改为自动换行；
   - 标题不与正文分页（`break-after: avoid`），列表项、表格行、图片、引用块不跨页拆开；
   - 段落 3 行孤行 / 寡行控制；
   - 保留原有底色与主题色（`print-color-adjust: exact`）。

## 文件

```
manifest.json      扩展清单（MV3）
src/content.js     核心：打印模式、全文加载、浮动按钮、打印样式、导出入口
src/epub.js        DOM → 干净 XHTML，并自建 STORE zip 打包成 EPUB 3
src/background.js  工具栏图标与快捷键 → 通知 content script 打印
icons/             16 / 32 / 48 / 128 图标
```

## EPUB 导出的转换规则

消息 DOM 走白名单转换，不直接拼接站点 HTML（站点用的是带哈希的 Tailwind 类，脱离页面 CSS 后不可读）：

- 保留 `h1-h6 / p / ul / ol / li / blockquote / pre / table / strong / em / code / a / img`；
- `div / span` 等布局容器摊平成文字，连续文字聚合成 `<p>`；
- 丢弃 `svg / button / script / style` 等界面元素与空的内联标签；
- 代码块输出为 `<pre><code>` 并保留原始换行，样式里自动折行。

## 已知限制

- 长回答（超过一屏）会跨页拆分，这是为了不产生大面积空白；标题、列表项等小块仍会避开分页。
- 如果页面用了「虚拟滚动」（只为可见区域渲染消息节点），滚动加载后仍可能缺失部分内容；
  当前分享页为全量渲染，未触发该问题。
- 用户消息处于「收起」状态时，被折叠的正文可能不参与打印；打印前手动点一次「展开」更稳妥。
- 页眉页脚（网址、日期、页码）由浏览器打印选项控制，不在插件管辖范围内。
- 浮动按钮可通过 `chrome.storage.sync` 的 `showButton`（设为 `false`）关闭。
- EPUB 打包用的是 STORE（不压缩），所以文件偏大：24 条消息约 48KB；换来的是不依赖任何第三方库。
- EPUB 里的图片走 `fetch` 内嵌，跨域受限或体积超过 8MB 的图片会被丢弃；单张上限 8MB、总量 40MB。
